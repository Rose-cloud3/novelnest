# NovelNest — Your Home for Endless Fiction

This is the GitHub Pages website package for NovelNest.

## Publish with GitHub Pages
1. Create a **public** GitHub repository named `novelnest` (or another name you choose).
2. Upload the contents of this folder so `index.html` is at the repository root and keep the `assets` folder alongside it.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/(root)`, then Save.
5. Wait for GitHub Pages to publish and open the website URL shown on the Pages settings screen.

## Story format
NovelNest is designed for mini-novels with approximately **20–25 short episodes per story**. The included stories and episode text are sample/demo content.

## Important prototype notes
- The included reader/admin experience is a front-end prototype.
- Story additions and uploaded poster previews are not yet stored in a shared online database; browser-only changes may not appear to other visitors and can be lost.
- Dashboard visitor figures are sample figures, not real analytics.
- A production version will need persistent storage and real analytics before using reader comments, accounts, or shared admin statistics.
